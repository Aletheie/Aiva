Lea přebírá tvůj projekt a potřebuje ho spustit bez pátrání ve starém chatu. Doplň návod k instalaci, spuštění a testům.

V cvičném projektu doplň README: požadavky, spuštění, testy, formát dat a omezení. Vyber jednu malou změnu, například opravu prázdného jména, a připrav pro ni samostatný commit i návrh popisu PR.

V popisu ukaž, co se dřív dělo, jak se chová opravený program a jak jsi to ověřila. Příkazy z README vyzkoušej v nové kopii. Hosting není nutný; stačí místní větev a review ve dvojici.

## Spuštění

Příkazy Git spouštěj v této samostatné cvičné složce. Při prvním commitu zkontroluj `git status` a připrav jen zamýšlené soubory. Vzdálený server není nutný pro místní nácvik.

Výchozí soubory obsahují příklad z výkladu. Uprav ho podle zadání a kontroluj běžné i hraniční vstupy.

## Ověření

- README obsahuje ověřené příkazy a cestu dat.
- Commit řeší jeden popsaný problém.
- Návrh PR neobsahuje klíče a vysvětluje ověření.
