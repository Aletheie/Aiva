Wednesday a Enid upravily první řádek týmového README, každá po svém. Git teď potřebuje rozhodnutí člověka. Pomoz zachovat obě změny v historii a do souboru dostat společný výsledek.

V nové cvičné složce vytvoř společný první commit. Podle lekce založ dvě větve, v každé změň tentýž první řádek README na jiný název a zkus je sloučit do `main`. Pouhé přepínání větví konflikt nevytvoří.

Dohodnutý název je `Java tým`. Vyřeš konflikt, odstraň jeho značky a dokonči merge commitem. Ověř čistý `git status` a historii obou větví. Pracuj pouze v tomto cvičném repozitáři.

## Spuštění

Příkazy Git spouštěj v této samostatné cvičné složce. Při prvním commitu zkontroluj `git status` a připrav jen zamýšlené soubory. Vzdálený server není nutný pro místní nácvik.

Výchozí soubory obsahují příklad z výkladu. Uprav ho podle zadání a kontroluj běžné i hraniční vstupy.
