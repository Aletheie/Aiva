Eliška pořádá filmový večer pro 100 lidí. Ještě zbývá poslední místo, ale rezervační program současně hlásí, že je vyprodáno. Pomoz jí poslat návštěvníkům jednu jasnou zprávu: kolik míst zbývá, zda je plno, nebo kolik zájemců už se nevejde.

`Main.java` načte počet zájemců od 0 do 200. Oprav větvení a výpočty tak, aby vypsal **právě jeden řádek**:

- méně než 100 lidí: `Volno: X`, kde X je počet zbývajících míst;
- přesně 100: `Vyprodano`;
- více než 100: `Chybi: X`, kde X je počet lidí bez místa.

Například 99 → `Volno: 1`, 100 → `Vyprodano`, 101 → `Chybi: 1`.
Před změnou kódu si pro tyto tři vstupy projdi, které podmínky se provedou.

## Práce s úlohou

Otevři tuto složku v editoru. Java soubory jsou v `src/main/java`.
Použij JDK 21 nebo novější a před kontrolou soubory ulož.
Nápovědy a vysvětlené řešení jsou v aplikaci.
